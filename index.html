        The dark mode problem, and what those two toggles do
        

          
Outlook's dark mode recolors plain text so it stays readable against a dark background — charcoal becomes white, and the orange job title gets swept up with it. It leaves link colors alone, which is why the website stays orange while the title doesn't.

          
Protect the title color wraps the job title in an anchor tag pointing at the company website. Outlook then treats it as a link and keeps the orange. In light mode it looks identical — the underline is suppressed and it isn't obviously clickable.

          
White card background sets an explicit light background behind the whole signature. Most clients respect an explicit background and skip inverting what sits on top of it, so the logo and all text render as designed. The trade-off is a white panel sitting in a dark email.

          
Dark mode handling differs between Outlook desktop, new Outlook, the web app, and mobile. Test in whichever your team actually uses — the preview toggle approximates it but can't perfectly reproduce any one client.

          
The logo is the harder half. Both marks are charcoal line art, which nearly disappears on a dark background. Only the white card fixes that.

        

      


      

        Why it's built with tables
        

          
Outlook on Windows renders email with the Word engine, not a browser engine. Flexbox, grid, and most modern CSS are ignored. Tables with inline styles are the only layout that survives it.

          
The divider rule is a one-pixel-tall table cell with a background color rather than an <hr> or a CSS border — those render inconsistently across clients, and a filled cell always shows up.

          
Fonts fall back to Segoe UI and Arial since Poppins won't load in a mail client unless the person has it installed locally. Links carry explicit colors so Outlook doesn't turn them blue.

          
Why the logo must be a hosted URL: base64-embedded images get stripped by Outlook and blocked by Gmail. If that address ever breaks, every signature you've already sent shows a broken image — so don't rename or move the file.
